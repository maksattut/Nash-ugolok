# Наш уголок

Кино, русские шашки и чат на двоих. Один открывает ссылку, второй заходит по приглашению — и вы смотрите одно и то же видео синхронно, переписываетесь и играете.

## Что умеет

- **Кино.** Вставляешь ссылку и жмёшь «Смотреть вместе». Плей, пауза и перемотка у одного происходят и у второго. Поддерживаются YouTube (обычные ссылки, youtu.be, shorts) и прямые ссылки на видеофайлы: `.mp4`, `.webm`, `.m3u8`. Кнопка с сердечком пускает сердечки по экрану у обоих.
- **Шашки.** Строгие русские правила: бить обязательно, простая бьёт назад, дамка летучая, превращение в дамку прямо во время боя с продолжением боя, турецкий удар запрещён. После каждой партии цвета меняются, счёт побед и ничьих сохраняется. Есть «предложить ничью» и «сдаться».
- **Чат** с индикатором «печатает…»; результаты партий и смена видео тоже появляются в чате.
- Комната задаётся параметром `?r=…`. Чат, счёт и текущая партия сохраняются в `data.json` и переживают перезапуск.

## Запуск у себя

```bash
npm install
npm start
# открыть http://localhost:3000
```

## Как выложить в интернет (Render, бесплатно)

1. Залей папку в репозиторий на GitHub.
2. На [render.com](https://render.com) → New → Web Service → выбери репозиторий.
3. Build command: `npm install`, Start command: `npm start`. Всё.
4. Открой выданный адрес, введи имя, нажми «Пригласить» и отправь ссылку.

Подойдёт любой хостинг с Node.js 18+ и WebSocket: Railway, Fly.io, VPS. На бесплатном Render сервер засыпает без посетителей, а файловая система не постоянная — для вечного хранения счёта подключи Disk и укажи путь в переменной `DATA_FILE`.

## Ограничения

- Страницы онлайн-кинотеатров (Кинопоиск, Netflix и т. п.) не проиграть: нужен YouTube или прямая ссылка на файл.
- Некоторые ролики YouTube запрещают встраивание — плеер об этом скажет.
- Если браузер не дал включить звук автоматически, появится кнопка «Присоединиться к просмотру».
